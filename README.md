# Fun-Walk

**Fun-Walk** — веб-приложение для планирования маршрутов прогулок с учётом пожеланий пользователя: зелёные зоны, велодорожки, качество воздуха, тихие места и набережные.

> Курсовая работа. Демо-режим использует симулированные данные по центру Москвы.

## Стек технологий

## Установка

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd Fun-Walk
```

### 2. Backend

```bash
cd backend
npm install
```

### 3. Frontend

```bash
cd ../frontend
npm install
```

## Запуск

Запускайте backend и frontend в **двух отдельных терминалах**.

### Backend (порт 3000)

```bash
cd backend
npm run start:dev
```

API будет доступен по адресу: http://localhost:3000

Проверка: http://localhost:3000/api/health

### Frontend (порт 5173)

```bash
cd frontend
npm run dev
```

Приложение откроется по адресу: http://localhost:5173

> Vite проксирует запросы `/api/*` на backend — CORS настраивать не нужно.

## Сборка для production

```bash
# Backend
cd backend
npm run build

cd frontend

```

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/health` | Проверка работоспособности |
| GET | `/api/defaults` | Точки старта/финиша по умолчанию |
| GET | `/api/poi` | Список точек интереса (парки, велодорожки и т.д.) |
| GET | `/api/routes` | Список сохранённых маршрутов |
| GET | `/api/routes/:id` | Детали маршрута |
| POST | `/api/routes/plan` | Построить новый маршрут |
| DELETE | `/api/routes/:id` | Удалить маршрут |

### Пример запроса POST `/api/routes/plan`

```json
{
  "start": { "lat": 55.7558, "lng": 37.6173 },
  "end": { "lat": 55.7293, "lng": 37.6017 },
  "preferences": {
    "greenZones": 7,
    "bikePaths": 5,
    "airQuality": 8,
    "quietAreas": 6,
    "waterfront": 4,
    "parks": 9
  },
  "name": "Моя прогулка"
}
```

## Как пользоваться

1. Откройте http://localhost:5173
2. Настройте **приоритеты** с помощью ползунков (0–10)
3. При необходимости измените **старт** и **финиш**, кликнув кнопку и затем точку на карте
4. Нажмите **«Построить маршрут»**
5. На карте отобразится маршрут, слева — метрики (дистанция, AQI, зелёное покрытие, балл)
6. Маршруты сохраняются в сессии и доступны в блоке «Сохранённые маршруты»

## Алгоритм планирования

Backend выбирает до 5 точек интереса (POI) между стартом и финишем, взвешивая:

- тип локации (парк, зелёная зона, велодорожка, набережная) по приоритетам пользователя;
- индекс качества воздуха (AQI);
- уровень шума;
- близость к прямой между точками.

На основе выбранных POI строится маршрут с промежуточными waypoints и рассчитываются метрики.
